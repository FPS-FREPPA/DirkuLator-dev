# 0.59rc repeated free-movement test protocol

Use one fully verified PPSA99862/00.005.059 package and preserve native accuracy.
Each run closes only this title, backs up/clears only the RADV/startup/native-GL
shader caches, launches, and selects New Game with the same dedicated test slot.
Require fresh opening and first-control observations. Record any cutscene skips.

The user requests natural free movement, replacing the older fixed route for
this candidate. Explore doors, interiors, ladders, bridges and camera angles;
record the actual path and return to recognizable house/forest views for optional
60-second comparisons. Repeated runs need not follow an identical route. Compare
FPS only in matched scenes/settings and mark collection/readback disturbances.

Automate telemetry every minute, verify collector heartbeat, and collect native
and user logs, kernel diagnostics, bridge requests/applied acknowledgments,
completed photo originals and GPU-capture manifests when available. Verify photo
hashes before deleting exact phone originals, preserve pending files, and archive
each run with original timestamps. Wait for two new completed images before first
analysis and a new image after each bounded input. Never run blind controls.

Watch NX2_FSEL_CORRECTED, task/mesh non-finite positions, index bounds, projected
spike heuristics, program IDs/payloads, visible geometry fans, fog, memory slope,
largest/total free ranges, allocations/reclaim, CPU/GPU/submit waits and frame
times. Correlate shader/draw evidence before attributing visible artifacts to
an opcode. Probe flags alone are not proof of corruption.

Target 30 minutes of controllable gameplay and 45 minutes from New Game per run,
unless it fails sooner. On crash/stall preserve companions before another launch,
close/reset, increment run number and begin New Game again promptly. Keep all failed
runs. Stop controls for lost observation, corruption, unavailable services or three
failed recovery attempts; preserve evidence and report the exact block.

At each run end stop the exact owned collectors/camera, verify final archives,
close the title and start the next run. At the user's deadline leave title closed,
camera stopped and evidence preserved. Report every run, collection gap, actual
gameplay time, matched-scene FPS/frame times, memory/OOM outcomes and graphics.
30 FPS and an OOM/geometry fix require sustained PS5 evidence. Keep private
logs/photos/game inputs out of public source. The local Luna handoff provides
the exact machine-specific commands and version guards.
